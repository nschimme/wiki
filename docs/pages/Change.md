This is a general command to **change** one of your parameters.

Use 'change &lt;parameter&gt;', where &lt;parameter&gt; is one of the following:

<div class="wiki-block">

   ``ALERTNESS``      changes how much attention you pay to hidden people<br>   ANSIFILTER     turns removal of special characters in whoises on and off<br>   `[`CHARSET`](./Charset.md)`        selects which character set your terminal supports<br>   `[`CLASS`](./Change_Class.md)`          changes your class<br>   `[`COLOUR`](./Colour.md)`         highlights certain text in color to make it more noticeable<br>   `[`DESCRIPTION`](./Description.md)`    changes the description others see when they look at you<br>   `[`EDITOR`](./Change_Editor.md)`         selects your editor for writing text<br>   `[`EQORDER`](./Change_Eqorder.md)`        customise equipment display order

</div>
`   HEIGHT         sets the number of lines before a page break for `[`PAGER`](./Change_Pager.md)
<div class="wiki-block">

   HTML           toggle to use the WWW-connection (disabled)<br>   `[`LANGUAGE`](./Language.md)`       selects another language to speak*<br>   `[`LINKDROP`](./Linkdrop.md)`       determines your connection's inactivity timeout<br>   `[`MOOD`](./Mood.md)`           changes how bravely you act when fighting<br>   PAGER          selects how you want long texts to be displayed<br>   `[`PASSWORD`](./Password.md)`       changes your password<br>   `[`SPELLCASTING`](./Change_Spellcasting.md)`   sets/shows default spellcasting effort<br>   `[`TITLE`](./Title.md)`          changes your title (only for heros and above); 'change<br>&nbsp;                 title none' removes the title**<br>   `[`WHOIS`](./Whois.md)`          changes the text people see when they use whois on you<br>   WIDTH          set screen width for output<br>   `[`WIMPY`](./Wimpy.md)`          lets you flee automatically when wounded<br>   WORDWRAP       toggles if you want long lines to word wrap<br>   `[`XML`](./XML.md)`            toggles XML-output on/off

</div>

- Remember to use one of the "standard languages" (whiteside: Westron)
  if you want to be understood by all players when using the Forgotten
  Tales (also known as [narrating](./Narrate.md)).

<!-- -->

- Note that you can not change your title while suffering Mandos Sleep.

More parameters might be available, type 'change' to have a complete
list. Ainu see /help change.

Example: \> change colour fight \> change language westron
